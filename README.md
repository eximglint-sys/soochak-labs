# Soochak Bharat Labs - Gemstone Verification System

A modern web application for verifying gemstone certificates and reports.

## Features

- Report number search and verification
- Beautiful, responsive UI
- Real-time report lookup
- Mobile-friendly design

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome Icons
- Google Fonts

## Project Structure

```
gemstones_pages/
├── index.html          # Landing page
├── report.html         # Report display page
├── app.js              # JavaScript functionality
├── style.css           # Styling
├── gemstone_reports.json  # Report data
└── assets/            # Images and logos
```

## Local Development

Simply open `index.html` in a web browser or use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (http-server)
npx http-server
```

Then visit `http://localhost:8000`
